# No joints or player-built machines in the MVP

Strokes never join: there are no hinges, welds or pivots, so no catapults, levers or drawn pendulums. The GDD's catapult and pendulum-trap combos are dropped; pendulums exist only as arena props. Building is about Lines (ramps, walls) and Objects (balls, boulders, bombs). The only runtime attachment is green Ink sticking to what it hits. Objects may touch but never overlap anything when drawn, because overlapping bodies fly apart violently when they wake.
