# Building happens during Waves, with an Intermission between them

Status: Accepted. Supersedes [ADR 0005](0005-wave-drawing-uses-wave-ink.md).

User testing showed that a paused Build Phase followed by a Wave in which only Wave Ink could be spent, and only inside the Core Zone, was less fun than managing the Ink that kills drop while the Wave runs. So the Build Phase, the Core Zone, Locked Ink and Wave Ink are gone (the code is kept at the git tag `build-phase-core-zone`). The Defence loop is now Wave → Intermission → Wave. During a Wave the player may draw anywhere, paying from the Ink Tanks, and every Drop goes straight into them; a Stroke closer than about one Enemy's width to an Enemy is refused, so Ink can't be drawn onto an Enemy. When a Wave ends, physics pauses and the Intermission begins: no drawing, a rewards screen (only a summary for now, built so a pick-1-of-3 choice can slot in), then every Tank refills to its maximum and every Object at rest is Frozen again (the GDD's Aftermath); the Arena otherwise stays as it ended, damage included. R retries the current Wave from right after that refill; Clear loads the Level again from Wave 1.

ADR 0005 existed to stop the dominant answer of dropping a rock on every Enemy. We now leave that problem to Ink scarcity and to Objects starting Frozen ([ADR 0004](0004-objects-start-frozen.md)): a rock drawn over an Enemy hangs there until it is Released or knocked loose, which costs a decision and timing, and every rock comes out of Tanks that refill only between Waves, so spending them on single Enemies leaves nothing for the rest of the Wave. The near-Enemy rule removes the cheapest form of it, drawing straight onto an Enemy. If playing shows rocks still dominate, the levers are the Tank maximums and prices, not a drawing zone.

Provisional, for manual testing: building in an Intermission, and once the Level is cleared, is allowed too (`buildBetweenWaves`, on by default); drawings made there are part of the checkpoint Space takes, so R keeps them. Undo (with its full refund) and drawing while a Wave is paused both stay allowed during a Wave. Both make the Wave easier than it should be, and either may be removed once playing shows whether scarcity holds without them; they are marked as provisional in `src/game/game.ts`.
