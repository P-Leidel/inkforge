# Campaign first, Roguelite Mode unlocked after it; MVP is Campaign only

The game starts as a fixed Campaign where Ink Tanks reset every Wave, so each Wave is a clean, fair puzzle that teaches the Colours. Beating the Campaign's final boss unlocks Roguelite Mode, where Ink carries over and the player picks upgrades. The MVP contains only the Campaign (no upgrades, Crawler/Runner/Heavy plus the Siege Walker, three short arenas plus a boss arena), because its job is to answer whether building under scarce Ink is fun. Roguelite Mode and procedural arenas come after that go/no-go test.
